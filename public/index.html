API key kenari.id

Key dipakai server untuk memanggil kenari. Tersimpan di server dan tidak pernah ditampilkan lagi (hanya bentuk tersamarkan). Claude tidak bisa melihat atau mengubahnya.

Key aktif
-

Key dicek ke kenari dulu (gratis, lewat endpoint saldo) sebelum disimpan. Berlaku langsung tanpa restart. Mengalahkan KENARI_API_KEY di .env.

Hanya admin yang login di web yang boleh mengubah key. Disarankan memakai key khusus untuk aplikasi ini di dashboard kenari, supaya mudah dicabut.

Model gambar default

Dipakai saat model tidak dipilih (web dan Claude). Harga per gambar dari kenari.

Model cadangan

Jika model default gagal (gangguan kenari, model bermasalah), server otomatis mencoba model cadangan sesuai urutan. Cadangan tetap tunduk pada batas biaya dan persetujuan Owner: cadangan yang lebih mahal dari yang disetujui dilewati. Maksimal 5.

    Log pemanggilan kenari

    Setiap generate/edit dicatat: model, hasil, durasi, dan perpindahan ke cadangan. Prompt tidak dicatat.

    Batas biaya pemakaian kenari

    Berlaku untuk web dan Claude (MCP). Isi 0 pada batas harian/mingguan/bulanan untuk tanpa batas. Claude tidak bisa mengubah batas ini.

    Permintaan yang biayanya di atas ambang butuh centang persetujuan Owner (web) atau approved=true (Claude). 0 = semua permintaan butuh persetujuan.

    Berlaku untuk tiap klien layanan, tambahan dari batas global di atas. 0 = tanpa batas per klien.

    Pemakaian saat ini (WIB)

    Biaya per klien

    Catatan biaya tetap tersimpan walau gambarnya sudah dihapus otomatis, jadi total mingguan dan bulanan tetap akurat.

    Daftar Style Guide

    Satu gaya dasar yang selalu dipakai, ditambah gaya per content pillar yang dipilih saat generate.

    Style baru

    Teks ini otomatis ditambahkan ke prompt (warna, maskot orisinal, gaya garis, suasana). Diisi Kenzo, disetujui Owner.

    Klien baru terdaftar otomatis saat Style Guide pertamanya disimpan. Klien tidak bisa diganti setelah dibuat. Isi gaya dasar klien dengan brand identity-nya (warna, gaya foto, nada visual).

    Hubungkan ke Claude (MCP)

    Cara termudah: konektor Claude (claude.ai / aplikasi desktop)

    1. Claude: Settings, Connectors, Add custom connector.
    2. Nama: Teman Seller Studio. Tempel URL di bawah, lalu simpan.
    3. Aktifkan konektornya di chat atau project yang memakainya.

    URL konektor belum aktif. Isi MCP_PATH_SECRET (minimal 24 karakter) di .env server lalu restart container.

    URL ini bersifat rahasia: siapa pun yang memilikinya bisa memakai tool MCP (dibatasi batas biaya). Hanya membuka MCP, tidak membuka dashboard. Ganti MCP_PATH_SECRET untuk mencabutnya.
